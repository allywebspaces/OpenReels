# AI Money India — creative brief

## Audience and language
Working Indians, 25–50. English narration with Indian examples.

## Format
Target 35–45 seconds, one idea per episode. This is creative guidance, not a guaranteed duration; measure the rendered output. Open with the subject in the first two seconds. Keep text inside mobile-safe margins. Use original scripts and properly licensed media.

## Script and evidence
One practical workflow, demonstrated honestly: problem, three steps, result, one action. Do not promise earnings or invent tool features. Use only verified product details. Do not fabricate screenshots or pass generated interface images off as a real demonstration.

## Visual direction
Clean bold illustration, large readable captions, simple diagrams. Prefer supplied real screen recordings for app demonstrations.
Default to AI stills, useful text cards and licensed stock. AI video is optional and explicitly enabled. Avoid decorative stock unrelated to narration. Prefer bundled low-volume background music.

## Closing action
A workflow checklist or template, only if it actually exists. No fictional links or sponsors.

## Review before publishing
Check factual sources, caption spelling, pronunciation, sound balance, visual relevance, duration and licensing. Review the actual MP4: the upstream critic evaluates the plan, not the finished film. No automatic public publishing in this milestone.

## Mandatory language guardrail
English only for narration, dialogue, captions, titles, descriptions, on-screen text and calls to action. No bilingual output or transliterated non-English dialogue. Translate source facts into English. Use romanized proper names where needed. This overrides any conflicting language direction.
